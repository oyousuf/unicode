This keyboard is used to write the Luo languages of Kenya and Tanzania, especially Dholuo, with the Luo Lakeside alphabet. The alphabet was created in 2009. Downloading the .exe file will download the keyboard and a typing manual showing all letters and how to use the keyboard.

You can easily switch to the new keyboard on your computer the same as switching between languages by clicking Alt+Shift, or clicking on the language in the bottom right of the Windows taskbar.
