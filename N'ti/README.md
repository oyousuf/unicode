This keyboard is used to write Soninke with the N'ti script. The script is an alphabet and was created in 1966 in Mali, but has since spread to Republic of Congo (Brazzaville) and Ivory Coast.

For Windows: Downloading the .exe file will download the keyboard and a typing manual showing all letters and how to use the keyboard.

For Mac: Download the .kmp file.

You can easily switch to the new keyboard on your computer the same as switching between languages by clicking Alt+Shift, or clicking on the language in the bottom right of the Windows taskbar.
