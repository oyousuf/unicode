This keyboard is used to write Bambara with the Masaba script. The script is a syllabary and was created in 1930 in Assatiémala, Kayes Region, Mali.

Downloading the .exe file will download the keyboard and a typing manual showing all letters and how to use the keyboard.

You can easily switch to the new keyboard on your computer the same as switching between languages by clicking Alt+Shift, or clicking on the language in the bottom right of the Windows taskbar.
